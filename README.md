# 🍷 Wine Quality Prediction

A machine learning web application that predicts the quality of wine based on various chemical characteristics (such as acidity, pH, residual sugar, and alcohol content). 

The project features a premium, dark-themed user interface designed for intuitive data entry using customized range sliders, and a backend prediction model.

## ✨ Features
* **Interactive UI:** Custom-styled range sliders with real-time value displays for easy data entry.
* **Premium Design:** A responsive, dark "laboratory" aesthetic with glowing gold and crimson accents.
* **Machine Learning Backend:** Takes 11 distinct physicochemical inputs to generate an immediate quality score.
* **Responsive:** Fully functional on both desktop and mobile devices.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Custom UI/UX)
* **Backend:** Python, Flask
* **Machine Learning:** [Numpay, Joblib, Scikit-Learn, RandomForestRegressor, Pandas]
